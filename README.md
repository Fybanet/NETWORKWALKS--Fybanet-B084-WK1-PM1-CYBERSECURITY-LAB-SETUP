# NETWORKWALKS--Fybanet-B084-WK1-PM1-CYBERSECURITY-LAB-SETUP
Networkwalks week1 task of building an isolated virtual lab with VirtualBox and Kali Linux for cybersecurity testing and penetration testing practice.    
This project is about creating a virtual lab for cybersecurity and testing security systems using VirtualBox and Kali Linux.

The lab is meant to provide a safe place to test cybersecurity tools, check networks, gather information, assess weaknesses, and do other security tests over and over again.

The lab is set up on a private virtual network. This means that we can easily add more computers later for approved security testing.
